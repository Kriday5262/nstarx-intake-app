# NStarX Intake App

Next.js 14 (App Router) scaffold with TypeScript strict mode, Tailwind CSS, shadcn/ui components, and Drizzle ORM.

## Brand tokens
- Primary purple: `#6464B4`
- Ink navy text: `#333F50`
- Lime accent: `#8CB428`
- Sky accent: `#64A0DC`
- Amber accent: `#E69138`
- Background: `#F4F6F9`

## Fonts
- Headings: Montserrat Black (900)
- Body: Nunito Sans

## Getting started

```bash
cp .env.example .env.local
npm install
npm run dev
```

## Scripts
- `npm run dev` — development server
- `npm run build` — production build
- `npm run lint` — lint
- `npm run db:generate` — generate Drizzle migrations
- `npm run db:migrate` — run Drizzle migrations
